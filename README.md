# DAWS.LIFE

Planificador personal: rutinas, pendientes, Workaholic, finanzas y objetivos.

- `index.html`: la app completa.
- `firebase-config.js`: los datos de tu proyecto de Firebase (lo único que se edita).
- `firestore.rules`: copia de las reglas de seguridad que se pegan en Firebase.
- `manifest.json` e íconos: para instalarla en el celular.

Tus datos no se guardan en este repositorio, sino en tu cuenta de Firebase.
